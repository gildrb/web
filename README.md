## gildrb.com

The source for [gildrb.com](https://gildrb.com), a static portfolio built with HTML, CSS, and vanilla JavaScript.

Run `node scripts/build-page.mjs` and `node scripts/verify-page.mjs` after source edits. After deployment, run `node scripts/verify-crawlability.mjs` to confirm the live site, Markdown references, sitemap, and LLM-facing endpoints are fetchable.

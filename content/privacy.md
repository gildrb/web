# Privacy

Canonical page: https://gildrb.com/privacy

gildrb.com is the personal portfolio of Gil Rodrigues (gildrb), operated as a static, hand-authored website. The site is served through Cloudflare's global content-delivery network. As with any CDN, Cloudflare processes the IP addresses of incoming requests to deliver pages and to protect the origin against abuse; that processing is governed by Cloudflare's own privacy policy. No other personal data is collected by this website.

Specifically: this site sets no cookies of its own, loads no third-party analytics, no tracking pixels, and no advertising scripts. The only value ever stored in your browser is a `theme` key in `localStorage` that remembers your light or dark mode choice; it never leaves your device and is not transmitted anywhere. The site embeds no social widgets, and the only external requests the pages make are for the site's own fonts and images, which are served from the same origin.

The public API endpoints (`/api/v1/profile`, `/api/v1/status`), the MCP server at `/mcp`, and the machine-readable files such as `llms.txt` and `sitemap.xml` contain no personal data beyond the professional identity information Gil Rodrigues chooses to publish about himself. Server logs, if retained at the CDN layer, are kept only for security and operational purposes and are not used to profile visitors.

If you have questions about this policy, contact [hi@gildrb.com](mailto:hi@gildrb.com). This page is the canonical privacy statement for gildrb.com; there is no separate data-controller register entry because no personal data is collected by the site itself.

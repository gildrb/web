About Gil Rodrigues (gildrb)

Gil Rodrigues, also known as gildrb (full name Gil Domingos Rodrigues Barbosa), is a brand designer based in Germany who builds identity systems for software. His work covers the full distance of a brand: strategy and verbal direction, logo and logomark construction, typographic systems, interface design, and the frontend implementation that ships the result to production.

The portfolio at gildrb.com is itself a case study in that practice. It is a hand-authored static site with a source-driven build: every case-study page is generated from authored Markdown, shares one design system, and is verified by a build-time test harness that checks markup structure, accessibility contracts, and machine-readable discovery files before anything is deployed. The same repo publishes llms.txt, llms-full.txt, an OpenAPI description, WebFinger identity, and a read-only MCP server so that search agents and AI tools can read the work without scraping markup.

Selected work includes the Filen identity system, the n0thing pixel wordmark, the CURVES free display typeface built from one geometric construction rule, the T3 logomark exploration, an unsolicited db monogram for developer Ben Davis, the mL7 channel identity, and Heph, a local document agent with cited, inspectable answers. Each case study documents not only the finished mark but the rejected directions that produced it.
